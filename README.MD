 # Funciones Básicas de Python — Actividad 3

## 📌 De qué trata este proyecto
Este repositorio corresponde a la **Actividad 3: Proyecto colaborativo** del curso de Ciencia de Datos. Su propósito es **investigar, documentar y ejemplificar al menos 30 funciones básicas de Python**, explicando su uso con ejemplos prácticos y funcionales, todo dentro de un Jupyter Notebook.

El trabajo se realizó en equipo (máximo 3 integrantes) utilizando **Git y GitHub** como herramientas colaborativas, donde cada miembro contribuyó con contenido, realizó confirmaciones  en momentos distintos y participó activamente en la construcción del documento. Se evidencia el trabajo continuo a lo largo de varios días, tal como lo exige la actividad.


## ✅ Objetivos cumplidos
- Documentación de **mínimo 30 funciones** con explicación clara y código funcional.
- Trabajo colaborativo con **commits de todos los integrantes**, en fechas y horas diferentes.
- Repositorio bien estructurado y documentado.
